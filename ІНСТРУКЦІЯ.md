# Мій щоденник — як поставити на iPhone (безкоштовно й назавжди)

Щоденник — це веб-застосунок. Його файли один раз викладаються в інтернет (безкоштовно, на GitHub Pages), а ти додаєш його на екран «Додому». Далі він працює як звичайний застосунок, навіть без інтернету.

**Твої записи та фото зберігаються тільки на телефоні.** На сайті лежить лише сама програма, без твоїх даних.

---

## Крок 1. Викласти щоденник (один раз, на Mac, ~10 хвилин)

1. Розпакуй архів `Diary-Web.zip`. Вийде папка з файлами (`index.html`, `app.js` тощо).
2. Зайди на **github.com** і створи безкоштовний акаунт (*Sign up*). Запам'ятай своє ім'я користувача, наприклад `oliviia-m`.
3. Угорі праворуч натисни **+** → **New repository**.
   - *Repository name*: `diary`
   - Вибери **Public**. Так треба для безкоштовного GitHub Pages; там лежить лише код, без твоїх записів.
   - Натисни **Create repository**.
4. На сторінці репозиторію натисни посилання **uploading an existing file**.
5. Перетягни у вікно **всі файли з папки** (не саму папку, а її вміст) і натисни **Commit changes**.
6. Відкрий **Settings** → зліва **Pages**:
   - *Source*: **Deploy from a branch**
   - *Branch*: **main**, папка **/ (root)** → **Save**.
7. Зачекай 1–2 хвилини й онови сторінку. Угорі з'явиться адреса на кшталт **https://oliviia-m.github.io/diary/** — це адреса твого щоденника.

## Крок 2. Встановити на iPhone

1. Відкрий цю адресу в **Safari**. Саме в Safari, не в Chrome чи Instagram.
2. Натисни **Поділитися** (квадрат зі стрілкою) → **На екран «Додому»** → **Додати**.
3. Відкривай щоденник **тільки з цієї іконки**.

⚠️ Записи в Safari і записи в іконці зберігаються окремо, тому пиши завжди з іконки.

---

## Резервна копія та новий телефон

**Налаштування → Резервна копія:**
1. **Створити резервну копію** — щоденник збирає все в **один файл `.diary`**: тексти, емоції, фото, фото місяців.
2. **Зберегти / надіслати файл** → «Зберегти у Файли» (краще в iCloud Drive), AirDrop або Telegram «Збережене».

**На новому телефоні:** відкрий свою адресу в Safari → додай на екран «Додому» → відкрий з іконки → **Налаштування → Відновити з копії** → вибери файл. Усе повернеться.

Раз на тиждень щоденник сам нагадає зробити копію.

## Що важливо пам'ятати

- **Не видаляй іконку щоденника з екрана «Додому».** Разом з нею iOS видаляє й записи (як при видаленні звичайного застосунку). Резервна копія від цього захищає.
- Якщо поставиш пароль і забудеш його, відкрити записи не вийде. Тому роби копії.
- Щоденних сповіщень веб-застосунок надсилати не може. Нагадування можна поставити в стандартних «Нагадуваннях» iPhone.

## Якщо щось не так

Зроби скриншот і надішли мені, я виправлю. Після виправлення достатньо знову завантажити оновлені файли в той самий репозиторій на GitHub (*Add file → Upload files*). Щоденник оновиться сам, а записи нікуди не подінуться.
